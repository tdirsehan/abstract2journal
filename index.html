Evidence-based journal matching

Abstract2Journal

Find journal matches from your abstract and keywords using OpenAlex semantic search, recent publication evidence, topic overlap, and real published articles.

Runs entirely on GitHub Pages. No account, server, or API key required for casual use.0 characters
The app first tries OpenAlex AI semantic search with a short, safe query. If that is unavailable, it automatically falls back to OpenAlex text search. Journal Fit is an evidence score, not an acceptance probability.

Article titles, journal names and article links come from OpenAlex records; the app does not invent references. DOI is preferred when OpenAlex supplies it. Always verify current aims & scope, indexing, quartile, APC and submission requirements on the journal’s official publisher website.
